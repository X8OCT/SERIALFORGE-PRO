# SerialForge PRO — C# .NET 8 (WPF) Desktop Application

Нативное Windows-приложение на **C# / WPF (.NET 8.0)** для высокоскоростного перебора (брутфорса), сканирования и анализа протоколов COM / RS-232 / RS-485 / USB-UART устройств.

---

## 🚀 Как запустить (3 простых способа):

### Способ 1: Двойной клик (Быстрый запуск)
Просто запустите файл **`run.bat`** внутри папки `csharp_wpf/`.

### Способ 2: Через командную строку / PowerShell
```bash
cd csharp_wpf
dotnet run -c Release
```

### Способ 3: Через Visual Studio / Rider
1. Откройте файл `SerialForgeWpf.csproj` в **Visual Studio 2022** или **JetBrains Rider**.
2. Нажмите **F5** (Пуск).

---

## 📦 Сборка в один автономный `.EXE` файл (Single-File Exe):

Чтобы получить один готовый `.exe` файл, который запускается на любом компьютере с Windows 10/11 без необходимости устанавливать .NET SDK:

1. Запустите скрипт **`build_exe.bat`**
2. Или выполните команду:
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./publish_exe
```
Готовый исполняемый файл будет лежать в папке:
`csharp_wpf/publish_exe/SerialForgeWpf.exe`

## 🛠 Возможности C# WPF приложения:
- **Прямой высокоскоростной опрос COM-портов**: Работа через `System.IO.Ports.SerialPort` с поддержкой аппаратного управления потоком (RTS/DTR), любых скоростей (от 300 до 921600+ бод).
- **Конструктор шаблона пакета**:
  - HEX и текстовые префиксы / суффиксы (`\r`, `\n`, `0x0D`, `0x0A` и т.д.)
  - Разрядность перебираемого ключа: 1, 2 или 4 байта (DEC, HEX, ASCII)
  - Порядок байтов (Endianness): Little-Endian и Big-Endian
  - Автоматический расчет контрольной суммы на лету: **CRC-16 Modbus**, **CRC-16 CCITT**, **CRC-8**, **Sum-8**, **XOR-8**
- **Умное авто-детектирование совпадения (Ключа)**:
  - Остановка перебора при получении заданного ответа (текстового `OK`, `ACK` или шестнадцатеричного HEX-шаблона)
  - Звуковое уведомление при нахождении ключа
  - Всплывающий баннер с найденным кодом и быстрым копированием в буфер обмена
- **Интерактивная таблица совпадений**:
  - Экспорт результатов в CSV-файл
  - Просмотр времени отклика (latency) и отправленных пакетов
- **Монитор последовательного порта (Терминал)**:
  - Живое логирование TX/RX с отметками времени до миллисекунд
  - Подсветка отправленных пакетов, входящих ответов и событий совпадения
- **Прямой HEX-трансмиттер**: Ручная отправка произвольных байтов в порт с расчетом CRC
- **Встроенный симулятор**: Возможность тестировать логику без подключенного физического оборудования!
